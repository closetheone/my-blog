上一篇《Hello World》之后，博客的前台开始往「好用」上磨。这一轮做了几件小事：目录、上一篇/下一篇、复制链接、404 随机文章。

## 文章目录（TOC）

长文最怕找不到章节。这一轮给每篇文章加了目录：

- 桌面端：右侧固定栏，滚动时高亮当前章节
- 移动端：顶部折叠面板，点开即用

实现上构建时从 Markdown 提取 h2/h3，渲染管线里用 `rehype-slug` 给标题补锚点 id，两边用同一个 `github-slugger` 生成规则，保证目录链接和正文标题对得上。

## 上一篇 / 下一篇

文章底部加了相邻文章导航：

| 位置 | 内容 |
| --- | --- |
| 左侧 | 上一篇（更新的一篇） |
| 右侧 | 下一篇（更早的一篇） |

只在已发布文章里找相邻，草稿和隐藏文章不会出现。首篇没有「上一篇」，末篇没有「下一篇」，空位留白不渲染。

## 复制链接

文章底部加了「复制链接」按钮，复制的是当前文章 URL，成功后按钮变成「✓ 链接已复制」，两秒后恢复。

```ts
async function copy() {
  await navigator.clipboard.writeText(window.location.href)
}
```

## 404 页随机文章

打不开的文章页现在不再是死胡同：除了「回首页」，还有一个「随机看一篇」按钮，跳到一篇随机已发布文章。

随机性放在请求时产生（`/api/random` 接口），因为 404 页是构建时静态渲染的，不能把随机结果写死在 HTML 里。

## 小结

这些都是小功能，但串起来读者在站内的动线就完整了：**找得到（TOC）→ 看得到上下文（上一篇/下一篇）→ 带得走（复制链接）→ 走丢了回得来（404 随机）**。
